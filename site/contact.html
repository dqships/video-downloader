Bugs · Ideas · Privacy

Vidzilla is an independent project. The quickest way to reach it is an issue on GitHub, where every report is read and you can follow what happens to it.

A site where Vidzilla doesn't work
Open an issue on GitHub with the page's address, what Vidzilla listed, and what you expected. Leave out anything private, such as links that only work while you're signed in.
Ideas and feature requests
Also through GitHub issues. Check the open ones first; adding to an existing request helps it more than a new one.
Privacy questions
Read the privacy policy first, then open an issue if it doesn't answer your question.
From the Chrome Web Store
The Support tab on Vidzilla's Chrome Web Store listing works too.
