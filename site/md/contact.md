# Contact

Bugs · Ideas · Privacy

Vidzilla is an independent project based in Michigan, USA. Email [{{supportEmail}}](mailto:{{supportEmail}}) for anything, or open an issue on GitHub, where every report is read and you can follow what happens to it.

## Something isn't working

The [support page]({{origin}}/support) has fixes for the most common problems.

## A site where Vidzilla doesn't work

[Open an issue on GitHub]({{repoUrl}}/issues/new) with the page's address, what Vidzilla listed, and what you expected. Leave out anything private, such as links that only work while you're signed in.

## Ideas and feature requests

Also through [GitHub issues]({{repoUrl}}/issues). Check the open ones first; adding to an existing request helps it more than a new one.

## Privacy questions

Read the [privacy policy]({{origin}}/privacy) first, then email [{{supportEmail}}](mailto:{{supportEmail}}) if it doesn't answer your question.

## From the Chrome Web Store

The Support tab on Vidzilla's Chrome Web Store listing works too.
