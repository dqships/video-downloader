Save the video you're watching.

Vidzilla is a Chrome extension that finds the video playing on a page and saves it to your computer as a file, at the quality the site sent. Nothing is re-encoded and nothing leaves your machine.

What it saves

Direct video files work today. Streams come next, in the order below. Protected video stays protected.

  1. VZ 01Saves now MP4
    WEBM
    MOV     Video files a page loads directly, at full size.
  2. VZ 02Next HLS .m3u8 streams, joined from their segments. You pick the quality.
  3. VZ 03Planned DASH .mpd streams, with the separate audio track put back in.
  4. VZ 04Planned M4A
    MP3     Just the audio, when that's all you want.
  5. VZ 05Planned VTT
    SRT     Subtitles, saved next to the video.
  6. VZ 06Planned LIVE Live streams, recorded from the moment you press save.
  7. VZ 07Never DRM Netflix, Disney+ and other protected video. Vidzilla shows it and leaves it alone.

What happens when you press save

Everything runs inside Chrome. There is no server, no companion app, and no account.

  1. 01

    It watches

    While a page plays, Vidzilla reads the requests Chrome is already making and keeps the ones that are video: files, HLS playlists and DASH manifests.

    GET harbour_1080.mp4 · video/mp4 · 148 MB
  2. 02

    It remembers how you got in

    It keeps the cookies, referrer and origin the page sent, so when you save, the site sees the same request it already allowed.

    Headers kept · cookie · referer · origin
  3. 03

    It fetches

    A background worker downloads the file in ranges and picks up where it stopped if the connection drops.

    Range 0–52 MB · dropped · resumed at 52 MB
  4. 04

    It joins

    Streamed pieces are joined in the browser without re-encoding, so the picture is exactly what the site sent. Arrives with HLS support.

    214 segments → one MP4 · no re-encode
  5. 05

    It saves

    The file lands in your Downloads folder, named after the page title. Rename it in the popup first if you want.

    Saved · Downloads/Night stomp over the harbour.mp4

Install

Vidzilla isn't in the Chrome Web Store. You load it yourself, which takes a minute.

  1. 3

    Build it

    You need Node 22 and pnpm.

    git clone https://github.com/dqships/video-downloader
cd video-downloader
pnpm install && pnpm build
  2. 2

    Turn on Developer mode

    Open chrome://extensions and switch on Developer mode, top right.

  3. 1

    Load it

    Click Load unpacked, choose the dist folder, then pin Vidzilla to the toolbar.
